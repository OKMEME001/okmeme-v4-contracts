# Security

Please do not use public GitHub issues to disclose an unpatched vulnerability that could affect deployed contracts or user funds.

Until a dedicated disclosure address is published, contact the OK.MEME team through the official project channels listed at <https://ok.meme> and request a private security contact.

This repository does not claim a third-party audit unless a report covering the exact commit is present under `audits/` and linked from the production deployment record.
